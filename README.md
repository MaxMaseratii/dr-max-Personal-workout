# Dr. Max Personal Work-out Program

Live app (after Pages is on):

**https://maxmaseratii.github.io/dr-max-workout/**

Open that link in Safari (iPhone) or Chrome (Android), then Add to Home Screen.

## Upload the app file

1. Download `dr-max-personal-workout.html` from the chat.
2. Open https://github.com/MaxMaseratii/dr-max-workout
3. Click **Add file** → **Upload files**
4. Drop the file in.
5. Rename it to **index.html** before you commit (click the pencil on the filename if needed, or upload then use the edit name).
6. Click **Commit changes**.

## Turn on GitHub Pages

1. Repo → **Settings** → **Pages**
2. Source: **Deploy from a branch**
3. Branch: **main** / folder: **/ (root)**
4. **Save**
5. Wait 1–2 minutes, then open the live link above.
